# Northern Cape telemetry-only pilot outreach

## Ask

Request a **telemetry-only** pilot dataset from a Northern Cape solar operator (or IPP asset manager). No physical control. No settlement claim until measured verification exists.

## Minimum dataset ask

1. Historical solar production (inverter or meter), ≥90 days preferred  
2. Inverter availability / alarm codes  
3. Export-limit history and any grid curtailment instructions (with issuer/reference if available)  
4. Weather forecast vs measured weather for the same window  
5. Site tariff / PPA terms (redacted commercials OK)  
6. Optional: BESS SoC, flexible-load constraints, electrolyser cost/performance  
7. Maintenance records and CAPEX/OPEX quotations if recovery options will be sized  
8. Agreed carbon factor for reporting  

## What GridFlex will deliver in return

- Loss detection with provenance labels  
- Advisory recovery ranking (execution locked)  
- Evidence pack with assumptions exposed  
- Pilot results screen comparing predicted vs realised **only after** measured baseline exists  

## Contact framing

> We are not asking to control your plant. We are asking for labelled telemetry so we can prove whether GridFlex correctly detects avoidable loss and ranks recovery options before any actuation discussion.
