# GCIP seven-minute presentation script

**Audience:** judges / programme reviewers  
**Mode:** advisory demonstration — physical plant execution remains **locked**  
**Data rule:** every number shown is **synthetic / illustrative** unless explicitly labelled measured pilot telemetry. Do **not** claim customer results.

## Timing board (7:00)

| Min | Screen | Spoken point |
|-----|--------|--------------|
| 0:00–0:45 | `/gcip` or `/gcip-demo` | Problem: SA already produces clean energy that is wasted at the connection. GridFlex turns loss into a recovery case. |
| 0:45–1:15 | Safe competition mode card | Data environment labelled demo; decision mode advisory; physical execution locked off. |
| 1:15–2:30 | Curtailment | Identify where energy is lost; keep cause tentative until evidence attached. |
| 2:30–4:30 | Recovery Centre | Run Northern Cape solar scenario. Rank options. Stress: **advisory only**. |
| 4:30–5:15 | Download recovery report | Open HTML. Point to assumptions and `synthetic_demo` — not customer settlement. |
| 5:15–6:15 | Platform Blueprint | How telemetry, provenance and safety locks fit together. |
| 6:15–6:45 | KPI & Reporting | Illustrative financial/carbon case only. |
| 6:45–7:00 | Close | Telemetry-only pilot ask. Hand over pilot request one-pager. |

**Do not tour every dashboard page.** Stick to: GCIP → Curtailment → Recovery → Blueprint → KPI.

## Must-say lines

1. “These figures are from a labelled synthetic competition scenario, not a live customer settlement.”
2. “Recommendations propose only — physical execution stays disabled for the pilot.”
3. “Next step is a telemetry-only pilot with clear data provenance.”

## Must-not-say lines

- Do not say “this plant saved R X last year” unless you have that customer’s measured settlement.
- Do not imply GridFlex is currently actuating BESS or electrolysers.
- Do not hide the Simulation / Provenance banners.

## Backup if live API is slow

1. Open pre-warmed tab set (see rehearsal checklist).
2. Fall back to offline recovery evidence in `go-live-reports/recovery-demo-*`.
3. Play the offline demonstration recording storyboard.
